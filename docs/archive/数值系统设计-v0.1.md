# 《预制黑客松模拟器》数值系统设计 v0.1（已废弃，由 v0.2 替代）

> ⚠️ 本文件已被《数值系统设计-v0.2.md》+《数值总表-v0.1.md》替代，仅留档勿用。

> 原则（owner 拍板）：
> 1. **数值不是摆设**。预算是硬约束：钱不够，花钱选项直接置灰不可选。
> 2. **怨气等隐藏值绝不在选项前透露**，只在选择后通过 HUD 脉冲 + 弹幕反馈。
> 3. 所有数值关系集中在本文件，JSON 数据以本文件为准生成。

## 1. 数值定义

### 1.1 明面数值（HUD 常驻，选项预览可显示）
| 键 | 名称 | 范围 | 说明 |
|---|---|---|---|
| `money` | 💰 预算 | 实数（元） | **硬约束资源**。`cost > money` 的选项置灰 |
| `buzz` | 📣 声量 | 0-100 | 影响赞助上门数、评委候选、媒体事件 |
| `gov` | 🤝 政商关系 | 0-100 | 影响领导事件、结局 |
| `rep` | 🏆 口碑 | 0-100 | 选手圈评价，影响结局 |
| `chaos` | 🌀 混乱值 | 0-15 | 多赞助累积，驱动三次爆炸 |

### 1.2 隐藏数值（选项预览不显示，选后反馈）
| 键 | 名称 | 范围 | 反馈方式 |
|---|---|---|---|
| `anger` | 😡 选手怨气 | 0-100 | HUD 半透明条脉冲 + 弹幕档位变化 |
| `risk` | 🎲 翻车风险 | 0-100 | HUD 温度计图标变色（绿<40 / 黄40-70 / 红≥70） |
| `conscience` | 🌱 良心值 | 0-100 | 仅选项按钮上的绿点暗示，数值永不显示 |
| `expect` | 🎈 期待值落差 | 0-100 | 不直接显示，赛后结算时体现 |

### 1.3 结构性数据（非数值）
- `patron`：金主类型（gov / corp / crypto）
- `titleTier`：Title 档位（1 朴素 / 2 宏大 / 3 离谱）
- `venue`：场地（campus / office / park）
- `sponsors[]`：已签赞助商（每家带 debts 条件列表）
- `judges[]`：5-9 位评委（controllable / strictness / streamer 隐藏属性）
- `strongTeamHandled`：第 7 队道德抉择结果（true=记下 / false=无视 / bought=想签约）
- `exposed`：是否被曝光长文（翻车实际发生）
- `awardMode`：颁奖方式（cash / delay / token / cert）

## 3. 预算流水（硬性收支表）

### 3.1 收入
| 来源 | 金额 | 条件 |
|---|---|---|
| 金主启动资金 | 5 万 / 12 万 / 20 万 | 序幕 |
| 赞助商签约（每家） | 3-15 万 | 见赞助商表；条件越苛刻钱越多 |
| 贿赂私信"细说" | +2 万 | E13，良心 -20、risk +25 |
| 赞助商尾款 | 签约额的 30% | 赛后结算；E11 拒绝加戏则 50% 概率取消 |

### 3.2 支出（预算不足=选项置灰）
| 项目 | 金额 |
|---|---|
| 场地：联合办公 / 高校 | 30,000 / 2,000（产业园 0） |
| 盒饭：15/30/60 元档 | 0（赞助供餐可覆盖）/ 8,000 / 20,000 |
| WiFi 专线 | 8,000（比赛中抢修 12,000） |
| 睡袋 / 酒店补贴 | 2,500 / 10,000 |
| 通稿夸大 | 5,000 |
| 压热搜 | 30,000 |
| 泡面报销 | 500 |
| 当场发奖金 | 奖金池实额（冠亚季 3+2+1 万基准） |
| 志愿者盒饭 | 含在盒饭档 |

### 3.3 平衡目标
- 政府开局（5 万）：不签赞助则必走"寒酸线"（15 元盒饭+公共 WiFi+睡袋都没有），良心线约需 2-3 家干净赞助或"结盟式谈判"
- 币圈开局（20 万）：可以全都要，但 chaos 与 risk 天然高
- **任何路线都不应出现"有钱就能全选好"的无脑局**：最贵组合（office 3万+60元盒饭 2万+专线 0.8万+酒店 1万+当场发奖 6万 ≈ 12.8 万）只有大厂/币圈开局或签约 ≥2 家才够，而签赞助必然带 chaos/debt

## 4. 明面数值增减规则

### 4.1 声量 buzz
- 主要来源：Title 档（+5/20/40）、通稿夸大（+5/+15）、直播事故（+15~20）、曝光长文（+20，负向流量）
- 作用阈值：buzz ≥60 → 赞助第 2 波上门；buzz ≥80 → 网红博主评委可选；结局【无人伤亡】要求 buzz <30

### 4.2 政商 gov
- 来源：配合领导（+5~10）、合影 C 位给领导（+10）、砍价赞助商环节（+5）
- 损耗：提醒领导控制时间（-5）、拒彩排（-8）、债主翻脸（-15）
- 阈值：gov ≥90 解锁结局【领导满意】；gov <20 政府线后续资源断绝

### 4.3 口碑 rep
- 来源：60 元盒饭（+5）、酒店补贴（+10）、当场发奖（+15）、按分数颁奖（+15）、滑跪补发（+5）
- 损耗：证书+合影发奖（-15）、拖欠奖金（-20，赛后兑现）、端水批发（-10）、装死处理曝光（-20）
- 阈值：rep ≥80 且 conscience ≥70 → 真结局【春风】

### 4.4 混乱值 chaos
- 每签 1 家赞助 +1；带评委席位/冠名奖项条件的 +2；房企/神秘赞助 +3
- 阈值：≥4 触发 E19 环节膨胀；含评委席位赞助 ≥2 触发 E20 债主冲突；≥6 概率触发 E21 评委互撕；冠名奖 ≥3 触发 E22 奖项通货膨胀
- 削减：砍环节（-2）、砍冠名奖（-3）、结盟式谈判（不加）

## 5. 隐藏数值规则

### 5.1 怨气 anger（赛后才揭盅）
- 增加：15 元盒饭 +20 / 不管住宿 +15 / 领导致辞装死 +20 / 断网装死 +10 / 环节膨胀照常 +25 / 拖欠奖金 +20
- 减少：60 元轻食 -10 / 酒店 -15 / 抢修 WiFi -15 / 泡面报销 -10 / 当场发奖 -10
- **档位**：<40 A 档吐槽弹幕；40-70 B 档阴阳怪气；≥70 C 档暴怒 + 比赛期随时可能触发 E18 提前曝光
- **赛后落差结算**：`最终口碑 += (expect - 实际体验分) / 5 的反向修正`——Title 越离谱、通稿越夸，落差惩罚越狠

### 5.2 翻车风险 risk
- 每次选择结算后检定：`roll(100) < risk` → E18 曝光事件插队
- 增加：内定冠军 +40 / 双冠军 +20 / 临时加队凑数 +20 / 贿赂私信 +25 / 代币发奖 +30 / 驱逐刷奖团 +5 / 拉拢刷奖团 +15 / 直播事故应对不当 +10~15 / 每届 chaos 每点 +2
- 减少：压热搜 -10 / 滑跪 -15 / 按分数颁奖 -10
- 直播倾向评委在场：risk 检定 ×1.5

### 5.3 良心值 conscience
- 增加：记第 7 队 +20 / 按分数颁奖 +25 / 当场发奖 +10 / 诚恳回应曝光 +15 / 结盟式谈判每次 +10 / 全拒赞助 +15 / 老实写通稿 +5
- 减少：内定 -30 / 装没看见刷奖团 -10 / 拉拢刷奖团 -15 / 贿赂私信 -20 / 端水 -10 / 代币发奖 -15
- 用途：解锁【春风】【意外真诚】【戒断反应】；高良心低声量时技术大牛评委愿来

## 6. 评审期计算模型

### 6.1 初榜生成
- 8 支队伍各隐藏真实质量分 q（第 7 队 q=95 固定最强；侄子队/上链队 q=40-55；刷奖团 q=60 但带"眼熟"标记）
- 每位评委打分 = q × 评委权重 + 偏好修正：
  - 较真度高的评委：贴近 q
  - 可被操控的评委：给债主队 +30
  - VC/币圈评委：无视 q，按"能不能发币"随机 ±40
- 初榜 = 全部评委加权平均（评委席膨胀 → 玩家自选票权重被稀释）

### 6.2 暗箱操作台三选一
| 选择 | 数值后果 |
|---|---|
| 按分数（第 7 队夺冠） | rep +15, conscience +25, risk -10；**债主翻脸**：每家未满足的债 gov -15 或尾款取消 |
| 内定债主队 | chaos 对应债主满意（gov +10）；risk +40；若 strongTeamHandled=true 弹幕爆炸（玩家良心被公开处刑） |
| 端水/双冠军 | money -10,000（奖杯制作费）, rep -10, risk +20；奖项数≥队伍数时直达【端水艺术家】 |

### 6.3 颁奖方式
| 方式 | money | anger | rep | risk |
|---|---|---|---|---|
| 当场转账 | -奖金实额 | -10 | +15 | 0 |
| 走流程 6 个月 | 0 | +20 | -10（赛后追 -10） | +5 |
| 等值代币 | 0 | +15 | -10 | +30（解锁【代币归零】） |
| 证书+合影 | 0 | +15 | -15 | +10 |

## 9. 数值体验目标（平衡验收标准）

1. **政府线**（5 万开局）：不签赞助玩不下去"体面局"，必须在钱和干净之间选 —— 预制线的入门引导
2. **币圈线**（20 万开局）：钱不是约束，chaos 和 risk 才是 —— 体验"赞助堆太多"的失控
3. **良心线**：全拒赞助 + 结盟谈判 + 60 元盒饭需要精打细算，能通关但 money 见底 ——【春风】必须是"穷出来的"
4. **怨气不可见但可感知**：玩家通过弹幕档位变化学会"读空气"，这是本游戏的核心技能
5. 单局 total 选择数 25-30 个，每个选择至少影响 2 个数值维度
