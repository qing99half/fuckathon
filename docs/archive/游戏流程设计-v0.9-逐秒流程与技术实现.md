# 《预制黑客松模拟器》v0.9 —— 逐秒流程与技术实现

> v0.9 更新（2026-09-01 第二轮对齐）：
> - 风口卡池扩充（12+ 个）；Title 保留朴素/宏大/离谱三档，每档多候选
> - 第一幕四大主线抉择固定：赞助 → 场地 → 后勤 → 评委；**评委候选人池受前置选择影响**
> - 双路线隐藏进入；卡牌 = 固定主线 + 随机插入；弹幕即时联动；翻车随时可爆
> - 像素小人纯氛围背景；**开局 Title 声量 + 场地选择决定小人数量与会场大小**
> - 单结局图鉴作为唯一 meta 目标
>
> 本文档粒度：一名典型玩家一整局（约 10 分钟 = 600 秒）的逐秒体验 + 每部分的实现方案。

## 第一部分：逐秒流程表

约定：「卡」= 全屏文字抉择卡（标题 + 梗文案 + 2-4 个选项按钮）；
「弹幕」= 从右向左飘过的选手内心 OS；「场景」= 像素小人会场画面。

## 第二部分：技术实现方案

### 2.1 技术栈与项目结构

> ⚠️ 本节已被《技术架构-v0.1.md》修订：**改用 Vanilla TypeScript + Vite，零运行时依赖**（不用 React/Tailwind），
> 引擎不碰 DOM、种子随机可复现、构建期内容校验 + 机器人模拟器。目录结构以架构文档为准。

```
src/
├── data/            # 全部内容数据（梗在这里，持续加）
│   ├── hypes.json       # 风口池（12+，权重、梗文案、数值修正）
│   ├── titles.json      # Title 词库（前缀/风口词/后缀 × 三档）
│   ├── patrons.json     # 金主
│   ├── sponsors.json    # 赞助商池
│   ├── judges.json      # 评委候选人池（tag 系统）
│   ├── cards.main.json  # 四大主线卡
│   ├── cards.event.json # 随机/条件事件卡池
│   ├── barrages.json    # 弹幕文案池（氛围池按怨气分级 + 联动池）
│   ├── teams.json       # 参赛队伍名/项目名生成器词库
│   └── endings.json     # 12 结局 + 判定规则
├── engine/
│   ├── state.ts     # 单局状态机（phase: intro→prep→hack→judge→award→end）
│   ├── deck.ts      # 卡组引擎：主线固定序列 + 条件事件插入 + 随机事件抽取
│   ├── stats.ts     # 五维数值 + 隐藏值（良心值/期待值/翻车风险）
│   ├── judgePool.ts # 评委池生成（按前置选择 tag 过滤）
│   ├── risk.ts      # 翻车检定（每次选择后 roll + 触顶插队事件）
│   └── ending.ts    # 结局规则引擎
├── components/
│   ├── Card.tsx         # 抉择卡（标题/梗文案/选项按钮/数值变化预览）
│   ├── Hud.tsx          # 数值条
│   ├── BarrageLayer.tsx # 弹幕层
│   └── PixelScene.tsx   # Canvas 像素会场
└── pages/  (Title / Game / Ending / Gallery)
```

### 2.2 关键系统实现

**① 卡组引擎（固定+随机）**
- 每局 = 一个事件队列：`[主线1赞助, 随机A, 主线2场地, 随机B, 主线3后勤(3连卡), 随机C, 主线4评委]`
- 随机事件带 `condition` 字段（如 `patron=crypto`、`venue=campus`），抽取时过滤；被选中的主线选择可向队列**注入**后续条件事件（签了币圈赞助 → 比赛期注入"赞助商要当场发 NFT 奖杯"）

**② 评委池 tag 系统**
```jsonc
// judges.json 候选示例
{ "id":"kol_coin", "name":"币圈 KOL 王老师", "tags":["crypto","hype"],
  "controllable":0.9, "strictness":0.1, "streamer":true,
  "flavor":"上一行代码写于 2011 年。", "line":"我就问一句，能发币吗？" }
```
- 生成规则：`patron=crypto` → 池里必含 2 个 `crypto` tag 候选；`titleTier=3`（离谱）→ 网红博主类答应率+；低声量+高良心值 → 技术大牛类愿意来

**③ 弹幕即时联动**
- 全局 `EventBus`：每次选项点击 → emit `choice:{cardId, optionId}` → BarrageLayer 查 `barrages.json` 联动表，2 秒内推 3-5 条关联弹幕（可选嘲讽/扎心分级）
- 氛围池：每 3-6 秒自动飘一条，文案池按怨气值分 3 档（吐槽 → 阴阳怪气 → 暴怒）
- 实现：绝对定位 div + CSS transform 动画，对象池复用，不超 12 条同屏

**④ 像素场景（纯氛围背景）**
- Canvas 2D，俯视 tilemap：尺寸 = 场地卡（小 480×270 / 中 640×360 / 大 800×450，多分区）
- 小人 = 8×8 像素 sprite，4 状态帧（敲代码/趴桌/走路/排队），状态机按怨气值加权随机切换；数量 = `base(Title 声量) ± 随机`（离谱 Title 触发"宣称 500 实到 40"彩蛋文案）
- 无寻路、无交互，30fps `requestAnimationFrame`；设施（餐台/睡袋区/C 位舞台）按后勤卡开关绘制
- 像素素材：程序化生成色块 sprite（零美术依赖，风格统一）

**⑤ 翻车系统（随时爆）**
- 每次选择结算后：`roll = random(100)`，若 `roll < 翻车风险值` → 立即向队列头部插队"曝光事件卡"

## 四、v0.9.1 修订：多赞助与混乱机制（2026-09-01 第四轮，覆盖旧条目）

> 现实修正：**预制黑客松的特征不是"挑一家赞助"，而是"来者不拒、疯狂堆砌"**。
> 赞助越多越有钱，但每一个赞助都在比赛期和评审期埋雷。
> 良心线的对照：AdventureX"与其兜售展位，不如结盟理想"——严格筛选，赞助少而干净。

### 4.1 新数值：🌀 混乱值（CHAOS）

- 每签一家赞助商：预算 +，混乱值 +1~3（按条件苛刻度）
- 混乱值明面显示，但后果是"预告片式"暗示："目前已签 4 家，评审环节可能有点挤。"
- 混乱值驱动三个系统：**环节膨胀、评委席膨胀、奖项通货膨胀**（见下）

### 4.2 赞助签约改为"招商大会"（覆盖第一幕主线卡 1/4）

不再是 3 选 1，而是**连续 2-3 波上门潮**，每家都是独立的"签/拒"抉择：
- 第 1 波（必有）：金主关联的 2 家
- 第 2 波（按声量）：2-3 家主动上门（"看到你们通稿了，10w+ 呢"）
- 第 3 波（条件触发）：离谱 Title/高声量解锁"神秘赞助商"（房企/微商/保健品，钱巨多条件巨离谱）
- 玩家可以全签、挑签、全拒。**全拒不是坏选择**——钱紧但评审干净，良心线入场券。
- 每签一家，弹出"合同摘要"卡：金额、条件（命题权/评委席位/口播时长/冠名奖项/展位）、一句小字梗

### 4.3 混乱值的三次爆炸

**爆炸 1 · 比赛期"环节膨胀"**（混乱值 ≥4 触发）
- 开幕式流程单事件卡："本场开幕式共有 6 位领导与赞助商代表致辞，预计 3 小时。"
- 口播时长累加：每家赞助商口播 10 分钟 → 总时长直接显示，弹幕实时倒计时
- 路演中插广告事件："速赚云要求在两组路演之间插播产品发布。"

**爆炸 2 · 评委席膨胀**（签约含"评委席位"条件的每家 +1 席）
- 评委席从 5 膨胀到最多 9：玩家自选席位被稀释
- 暗箱难度机制改变：人越多，票数越分散，**债主之间互相冲突**
  - 例：速赚云要侄子队夺冠，宇宙链要"上链队"夺冠——**暗箱台只能满足一方，另一方当场翻脸**（撤资/差评/发朋友圈阴阳）
- 混乱值 ≥6 解锁专属事件"评委互撕"：路演现场两位评委吵起来，弹幕直播式围观

**爆炸 3 · 奖项通货膨胀**（评审期高潮演出）
- 每家冠名赞助商 = 一个冠名奖项："速赚云·最佳云原生奖""宇宙链·最具上链潜力奖"
- 奖项数 vs 队伍数对比卡："本届共设 11 个奖项，参赛队伍 8 支。"
- 弹幕："获奖率 137%，比我们学校奖学金好拿。"
- 奖项数 ≥ 队伍数 → 【端水艺术家】结局权重大幅提升

### 4.4 对旧文档的覆盖说明

- 第一幕时间轴中"主线卡 1/4 · 赞助谈判"替换为"招商大会"（2-3 波，总时长扩至约 60-75 秒，第一幕相应扩到 ~3.5 分钟，从比赛期匀 30 秒）
- 第三幕暗箱操作台增加"债主冲突"层：人情债清单改为分阵营（按赞助商分组），多债主冲突时强制二选一
- 数值系统增加 🌀 混乱值；翻车风险公式中混乱值权重 +（赞助越多，曝光时"奖项通货膨胀"越容易被截图嘲讽）
- 新增结局 **【赞助商年会】**（赞助商 ≥6 且未翻车）：图鉴扩容为 13 个
  > "领导致辞时说了三次'感谢主办方'，但你数了，台上站着的全是赞助商。包括你——你也是来蹭的。"

### 4.5 良心线的对称设计

- 签约时可选择"结盟式谈判"（隐藏选项，良心值足够时出现）：拒绝冠名奖项、拒绝评委席位、只接受物资赞助 → 金额减半但混乱值不加
- 弹幕对照：良心线赞助少时弹幕是"这场子好素，但是好舒服"；预制线赞助多时弹幕是"这是黑客松还是赞助商年会，我分不清了"
