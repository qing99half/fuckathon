## 1. 四条铁律

1. **预算是硬约束**：`花费 > 当前预算` 的选项置灰不可选（像素锁图标 + "预算不足"）。
2. **明隐分离**：选项预览只显示明面数值（预算/声量/政商/口碑/混乱）；怨气、翻车风险、良心值、期待值**永远不在选项前出现**，选后由 HUD 脉冲 + 弹幕反馈。
3. **四档幅度制**：任何选项对任何数值的影响只允许取 4 档（见 §3），保证手感可学习。
4. **因果确定，反应随机**：玩家自己的选择 → 后果确定；外部世界（赞助商、评委、媒体、网友）的反应 → 才允许掷骰子，且概率 + 修正项全部明示（见 §5）。

## 3. 四档幅度阶梯（全游戏唯一的数值生成规则）

| 档 | 幅度 | 用于 | 例子 |
|---|---|---|---|
| S 档 · 挠痒 | ±5 | 顺带一提的小事 | 通稿老实写：buzz +5 |
| M 档 · 有感 | ±10 | 常规选择的常规后果 | 酒店补贴：rep +10 |
| L 档 · 肉疼 | ±20 | 核心张力选择 | 15 元盒饭：anger +20 |
| XL 档 · 伤筋动骨 | ±30~40 | 全局性抉择（每局 ≤5 处） | 内定冠军：risk +40；按分数颁奖：conscience +25 |

规则：
- 一张卡的选项之间必须**拉开至少一档**（避免"选哪个都差不多"）
- 同一数值在单局内被 ±40 影响的次数 ≤2（内定、翻车级事件专属）
- 混乱值例外：步长固定为 +1（普通赞助）/ +2（带评委席位或冠名权）/ +3（神秘赞助），不走四档

| 事件 | 概率公式（全部死数） | 逻辑 |
|---|---|---|

| E09 刷奖团出没 | 基础 **50%**；buzz ≥60 时 **80%**（闻到流量） | 声量引来的外部苍蝇 |
| E11 赞助商突袭加戏 | 基础 **30%**；每多签 1 家赞助 **+10%**，上限 70% | 赞助商的外部反应 |
| E11 拒绝加戏的尾款 | **50%** 概率尾款取消 | 对方翻脸是外部反应 |
| 币圈金主尾款 | **30%** 概率"再研究研究" | 币圈特色 |
| E14 币圈评委失联 | 评委团含币圈 KOL → **30%** | 对方的外部行为 |
| E15 直播事故 | 评委团含网红博主 → **40%** | 对方的外部行为 |
| E06 志愿者缺席混乱 | 不收志愿者 → 签到混乱 **40%**（anger +10） | 人手不足的自然后果 |
| E02 同行撞期 | **30%**；若 Title=离谱档再 **+20%**（同行也爱蹭大词） | 外部竞争 |
| E01 冠军打听 | **40%**；上届若内定过（多周目标记）**80%** | 圈子的外部记忆 |
| E12 泡面门 | 住宿=不管 或 盒饭=15 元 → **70%** | 后勤选择的自然后果 |
| 翻车检定（核心） | **每次选择结算后：roll(100) < risk 即触发 E18 插队**；评委团含直播倾向者时 risk 按 ×1.5 计 | 唯一的高频骰子，玩家通过温度计可感知 |

设计约束：
- **概率触发的事件，其概率必须能被玩家至少一个前置选择影响**（没有纯天降倒霉）
- 单局概率事件触发数软上限 4 个（防止骰子喧宾夺主；条件触发不受限）

## 5. 评审期计算模型（确定性为主）

1. **队伍真实质量分 q**（隐藏）：8 队；第 7 队 q=95 固定；债主队 q 在 40-55 由 seed 定；其余 60-85
2. **初榜**：每评委输出分数 → 加权平均
   - 较真度高的评委：输出 = q ± 5
   - 可被操控的评委：债主队 +30，其余 = q
   - VC/币圈评委：输出 = 50 ± 40（纯随机，唯一允许的内部骰子）
   - **评委席膨胀 = 玩家自选票权重稀释**：5 席时自选占 3 席 → 9 席时自选仍 3 席
3. **暗箱三选一**（后果全确定，数值见总表）：按分数 / 内定 / 端水或双冠军
4. **债主翻脸**：内定某债主 → 其余债主 gov -15 或尾款取消（确定，不掷骰）

## 6. 赛后结算公式（期待值落差的兑现点）

```
最终口碑 rep_final = rep + 落差修正
落差修正 = round((实际体验分 - expect) / 5)
实际体验分 = 100 - anger   （怨气即体验的反义词）
```

- 例：离谱 Title + 夸大通稿（expect=80）+ 怨气 60 → 修正 = (40-80)/5 = **-8**，口碑倒扣
- 良心线：expect 低 + anger 低 → 修正为正 → 口碑白赚
- **"吹得越狠、摔得越重"由这一条公式统一兑现**

## 8. 平衡验收标准（开发完成后逐条验证）

1. 政府线（5 万开局）：不签赞助必走寒酸线；良心线需 2-3 家干净赞助或结盟谈判
2. 币圈线（20 万开局）：钱不构成约束，chaos 与 risk 才是
3. 【春风】必须 money 见底才能达成——良心是穷出来的
4. 最贵组合 ≈12.8 万（office 3万 + 60元盒饭 2万 + 专线 0.8万 + 酒店 1万 + 当场发奖 6万），大厂/币圈开局或签约 ≥2 家才够
5. 单局选择数 25-30 个，每个选择至少影响 2 个维度；概率事件 ≤4 个
