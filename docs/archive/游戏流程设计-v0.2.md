## 一、已确认的设计决策（来自 owner 2026-09-01）

| # | 决策项 | 结论 |
|---|---|---|
| 1 | 玩法类型 | **文字事件选择**为主（类 Reigns 卡牌抉择，不做重数值经营） |
| 2 | 路线设计 | **双路线**：预制线（糊弄）+ 良心线（认真办），讽刺预制、致敬良心 |
| 3 | 单局时长 | **10 分钟左右**轻量局 |
| 4 | 评委与暗箱 | **评委选择做成独立系统**（怎么选评委是核心玩法之一）；暗箱操作粒度 = **内定冠军是哪队**（不做逐队调分） |

| 7 | 文案 | **梗密度是游戏核心卖点**，素材来自小红书/抖音/贴吧真实吐槽；文案要"很有梗" |
| 8 | 上线方式 | GitHub + Vercel，纯前端 |

## 二、对标框架：AdventureX Playbook（良心路线的事实依据）

AdventureX 开源了完整办赛手册（github.com/AdventureX-RGE/Playbook），
其宣言直接点名了我们的讽刺对象："黑客松正沦为计算 ROI 的流量池、变相的招聘会"。

**Playbook 章节结构（= 良心路线的游戏关卡清单）：**

- 筹备期：体验设计（反向规划）→ 预算（把钱烧在理想的火堆上）→ 场地（避难所）→ 物资 → **赞助（与其兜售展位，不如结盟理想）** → 内容营销（诚实是最好的营销）→ 传播节奏 → 选手招募筛选
- 现场期：签到（第一小时决定五天心情）→ 开幕式（建立共同使命）→ 军火库（105% 物资冗余）→ 子活动节奏（Workshop/蓝调/UGC）→ **餐饮（食物是秩序与战斗力，24h 补给台）** → 睡眠（两层休息：短睡与深睡）→ 媒体 → 秩序 → **评委接待（被尊重但不被特殊化，每位评委配 Handler，评委匿名）** → Demo Day（展台集市式评审，拒绝路演过场）
- 赛后：反馈 24h 内落地、经验开源给下一个城市

**游戏化映射：良心路线的每个"正确选择"都有 Playbook 原文背书；
预制路线的每个"糊弄选择"都是 Playbook 警告的反面。两条路线共用同一套事件卡，选择不同、弹幕和结局不同。**

## 三、单局结构提案：五幕制（目标 10 分钟）

```
序幕（~1 min）  立项：抽风口 + 起 Title + 金主上门
第一幕（~3 min）筹备期：8-10 张事件卡（赞助/场地/宣传/后勤/规则）
第二幕（~2 min）比赛期：像素小人场景 + 4-5 张事件卡 + 弹幕爆发
第三幕（~2 min）评审期：评委阵容组建 → 路演 → 暗箱操作台（内定冠军）
第四幕（~2 min）颁奖与结算：颁奖典礼选择 → 多维结算 → 结局卡
```

### 各幕要点

**序幕 · 立项**
- 抽"风口卡"（AI Agent / 具身智能 / Web3 / 元宇宙遗老……影响赞助难度与媒体热情）
- 起 Title 三选一：朴素 / 宏大 / 宏大得离谱（如"首届全球宇宙级新质生产力开发者极客巅峰盛典"）
- 金主类型三选一：地方政府（要政绩）/ 大厂 PR 部（要曝光）/ 币圈基金会（要发币）

**第一幕 · 筹备期（卡牌抉择）**
核心张力：每个决策都是"省钱/省事 vs 选手体验 vs 翻车风险"的三难。
- 赞助谈判卡：赞助商要求命题权 / 评委席位 / 开幕式口播时长，接受程度换金额
- 场地卡：政府免费园区（偏远+领导要来）vs 自费市区场地
- 宣传卡：通稿夸大倍数选择（"预计 500 人参赛"实际 40 人）
- 后勤卡：盒饭标准 15/30/60 元、WiFi 档次、睡袋有无
- 评委邀请卡（独立系统入口）：见第四节
- 规则卡：是否在细则里给自己留后门（"最终解释权归主办方所有"）

**第二幕 · 比赛期（像素小人场景 + 弹幕）**
- 画面：俯视像素会场，小人敲代码/趴桌/排队领饭/抢插座，状态随"选手怨气"数值变化
- 弹幕系统：选手内心 OS 飘过屏幕（梗密度最高的地方，见第六节）
- 事件卡：领导致辞超时 / WiFi 崩了 / 职业刷奖团入场 / 有队伍真做出了好东西（道德抉择点）/ 赞助商临时加广告

**第三幕 · 评审期**
- 评委阵容确认 → 路演蒙太奇（每队一句话概括 + 弹幕吐槽）
- **暗箱操作台**：本届累积的"人情债"列表（赞助商侄子队 / 领导推荐队 / 自己人队），
  玩家决定冠军归属：真给最强队 / 内定某队 / 端水批发奖项（"最佳创意奖""最佳 UI 奖"人手一个）
- 翻车风险实时显示

**第四幕 · 颁奖与结算**
- 颁奖选择：领导讲话时长 / 奖金发放方式（当场转账 / 走流程 6 个月 / 等值代币 / 证书+合影）
- 结算面板：💰 剩余预算 / 📣 声量 / 🤝 政商关系 / 🏆 口碑 / 😡 选手怨气爆发判定
- 结局卡（收集图鉴）：《圆满交差》《预制菜大师》《无人伤亡》《10w+ 长文曝光》《意外真诚》《春风》……

## 四、评委选择系统（独立子玩法）

筹备期的核心决策之一，评委阵容 = 5 个席位，候选人池每局随机：

| 评委类型 | 明面效果 | 隐藏效果 |
|---|---|---|
| 真·技术大牛 | 评审质量高、口碑+ | 不好操控，可能当场拆穿水项目 |
| 赞助商市场总监 | 赞助费+、政商+ | 必投自家关系户，"上一行代码写于 2011 年" |
| 投资人 VC | 声量+ | 只问商业模式，"能不能发币？" |
| 高校教授 | 政商关系+ | 打分看 PPT 美观度 |
| 网红科技博主 | 声量++ | 全程直播，暗箱易被拍下来 |
| "领导的朋友" | 政商++ | 完全不懂，致辞还要加 20 分钟 |

**原则（来自真实吐槽）："评委一定要懂产品，做游戏的一定要玩游戏"——
良心线凑齐真懂行的评委解锁特殊结局；预制线堆关系户评委则暗箱更容易但翻车风险++。**

## 五、数值系统（轻量，服务叙事）

- 💰 预算 / 📣 声量 / 🤝 政商关系 / 🏆 口碑：0-100，卡牌选择增减
- 😡 选手怨气：隐藏进度条，通过弹幕"剧透"（怨气越高弹幕越阴阳怪气）
- 🎲 翻车风险：暗箱操作累积，颁奖时判定
- 良心值（隐藏）：良心选择的累计，决定能否进入良心结局线

## 六、梗素材库（持续扩充，第一批）

**真实事件改编：**
1. 奖金发"等值代币"，半年后币价归零（真实案例：某链黑客松）
2. 赛前 50+ 条私信贿赂打听比赛结果（真实案例：Solana AI 黑客松）
3. 主办方为避免争议直接取消 Demo Day（真实案例：同上）
4. 领导致辞 1 小时，选手开发时间被压缩
5. 盒饭 15 元标准 vs 宣传稿"精美茶歇"
6. "预计 500 人参赛"，现场 40 人，合影靠 P 图
7. 评委是市场总监，提问"你这个能不能给我们导流"
8. 职业刷奖团：同一套 PPT 换个 Title 全国巡回领奖
9. 奖品是证书 + 和领导合影
10. 选手 48h 作品，评审 5 分钟走完过场

**弹幕文案示例（比赛期）：**
- "这个插座是我用命换来的"
- "WiFi 又断了，我用热点写了三小时"
- "隔壁队好像是赞助商侄子，懂了"
- "盒饭里的鸡腿是本周唯一的高光"
- "凌晨四点，主办方的摄影师又来拍我们睡觉了"

**金句原则：**"评委一定要懂产品，做游戏的一定要玩游戏。"

## 七、技术方案（预研）

- 纯前端：React/Vue 或原生 + Tailwind；像素场景用 Canvas 或 CSS sprite
- 内容驱动：全部事件卡/弹幕/结局做成 JSON 数据文件，方便持续加梗
- 部署：GitHub 仓库 + Vercel 自动部署
- 无后端，存档用 localStorage（结局图鉴收集）
