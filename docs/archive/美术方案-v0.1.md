# 《预制黑客松模拟器》美术方案 v0.1

> 目标：**截图即传播**。UI 舒服到玩家愿意录屏，结局卡美到玩家主动发小红书。
> 一句话风格定位：**「红头文件 × 像素游戏」——体制内荒诞感 + 黑客文化复古感**。

---

## 1. 风格概念

游戏的美术本身就是梗：

- **筹备期 / 评审期 / 颁奖期（UI 卡片）**：模拟一套"组委会办公系统"。
  事件卡 = 系统弹窗；赞助协议 = 合同样式卡；通报/通稿 = 红头文件样式。
  干净的排版 + 一本正经的格式 + 荒诞的内容 = 讽刺张力。
- **比赛期（像素场景）**：俯视像素会场，CRT 扫描线滤镜，昼夜循环。
  从"办公系统"切进"像素世界"的反差，本身就是情绪切换点。
- **结局卡（分享图）**：像素插画 + 红头文件式通报排版 —— "XX 组委会文件"的荒诞正式感。

参考气质：Papers, Please（体制的冰冷）× Reigns（一屏一决策）× 国产贴岗表情包（红头文件梗）。

## 3. 字体系统

| 用途 | 字体 | 说明 |
|---|---|---|
| 像素标题/LOGO/大数字 | **Fusion Pixel（缝合像素字体）** | 开源免费，支持中文，12px 像素风，CC 协议可商用 |
| 英文/数字像素点缀 | **Press Start 2P** | Google Fonts 免费，用于 HUD 数值、"GAME OVER"式标题 |
| 正文/选项 | **思源黑体 / 系统黑体** | 阅读舒适优先，梗再密也要看得清 |
| 弹幕 | 思源黑体 Bold / monospace 混用 | 白字黑底胶囊 |
| 红头文件样式 | 思源宋体 Bold | "XX 组委会文件"的严肃感全靠宋体 |

字号阶梯：正文 16px / 卡片标题 22-24px / 结局卡大标题 72px+ / 弹幕 14px。
原则：**每屏一个决策，正文不超过 3 行，梗的密度靠弹幕和详情页承担**。

## 4. 核心组件规范

### 4.1 抉择卡（核心组件，占游戏 80% 时间）
```
┌─────────────────────────────┐
│ ▓▓ 组委会办公系统 · 弹窗 #07 ▓▓│ ← 窗口标题栏（像素字体，带"假关闭按钮"装饰）
│─────────────────────────────│
│  WiFi 崩了                    │ ← 事件标题（22px 粗）
│                              │
│  公共 WiFi 在第 47 个人连接    │ ← 正文（16px，≤3 行）
│  时停止了思考。               │
│                              │
│ ┌─────────────────────────┐ │
│ │ 现场加钱拉专线 ¥12000     │ │ ← 选项按钮：全宽、大点击区
│ └─────────────────────────┘ │    hover 时预览**明面数值**：
│ ┌─────────────────────────┐ │    「预算-12000 · 口碑+8」
│ │ 让选手用手机热点          │ │    ⚠ 怨气/翻车/良心等隐藏值
│ └─────────────────────────┘ │    **绝不在选项前透露**，
│ ┌─────────────────────────┐ │    选择后通过 HUD 跳动+弹幕反馈
│ │ 宣布"断网也是黑客精神"    │ │    （良心向选项带绿点⚪，不解释）
│ └─────────────────────────┘ │
└─────────────────────────────┘
```
- 入场动画：窗口弹入 150ms + 打字机音效
- **预算硬约束**：花费选项在预算不足时置灰不可选（按钮变灰 + 像素锁图标 + 小字"预算不足"），
  玩家必须先搞钱（签赞助）或选免费方案——预算是真实资源，不是摆设
- 选择反馈：按钮按下 → 明面数值条跳动（红跌绿涨）→ 怨气条只做脉冲闪烁不标量 → 200ms 后下一张卡
- **绝对不堆信息**：更多细节藏在标题栏的"查看附件"里（点开是梗文档，如赞助合同全文）

### 4.2 HUD 数值条（常驻顶部）
`[金币像素图标] ¥47,000 | [喇叭图标] 62 | [握手图标] 45 | [奖杯图标] 38 | [火苗图标] ▓▓▓░░（半透明）`

> **全局规则：UI 内禁止任何 emoji。** 所有图标（数值、选项标记、状态提示）一律使用预制的 16×16 像素 PNG 图标（见《美术资源清单》UI 图标组），保证风格统一、去除 AI 质感。

- 像素字体数字 + 8px 高进度条
- 怨气条故意做得"半透明、没标数字"——玩家能感觉它涨了，但永远不确定多少会爆（焦虑感来源）
- 翻车风险不显示数值，用 HUD 右上角一个"热搜温度计"像素图标颜色暗示（绿→黄→红，三帧像素图）

### 4.3 弹幕
- 样式：白字、黑底 60% 透明、圆角胶囊，从右向左匀速飘过
- 分轨：上中下 3 条弹幕轨，避免重叠；同屏 ≤12 条
- 档位联动：怨气 A 档白色 / B 档微黄 / C 档前缀像素火焰图标且速度加快
- 联动弹幕（玩家选择后触发的）：从选项按钮位置"发射"出来，视觉因果明确
- 比赛期弹幕飘在像素场景上层 = 玩家在读选手的内心；**这是全游戏传播截图最多的画面，字号和对比度按手机截图可读性调**

### 4.4 像素小人场景
- Tile 16px，整体放大 3 倍渲染（像素锐利，关闭抗锯齿）
- 小人 8×8 sprite：4 状态（敲代码=头上下点动 / 趴桌 / 走路 / 排队），发色衣服随机 16 色
- 设施贴图：长桌、笔记本（屏幕发光色随机）、餐台、睡袋堆、舞台、领导讲台
- 昼夜循环：全局叠加色 + 灯光层（深夜时每台笔记本是一个光源）
- 摄影师小人随机出现、闪光灯一亮——玩家看到就知道"又在拍你们睡觉了"
- 怨气可视化：小人趴桌比例 = f(怨气)；C 档时有人站在椅子上（弹幕配合）

### 4.5 结局卡 / 分享图（**传播核心，最高优先级**）
- 尺寸 **1080×1440（3:4，小红书/朋友圈直发）**，Canvas 2x 渲染导出 PNG
- 布局：
```
┌────────────────────────┐
│ ███ 组 委 会 文 件 ███ │ ← 红头文件带（政务红底白字宋体）
│  预字〔2026〕第 07 号   │ ← 发文字号（梗：文号=结局编号）
│ ────────────────────── │ ← 红头文件经典红线
│                        │
│   [像素插画 640×480]    │ ← 每结局一张像素场景画
│                        │
│      预制菜大师         │ ← 结局名（72px 像素字体）
│                        │
│  你的黑客松被做成了教学  │ ← 结局文案（宋体，文件口吻）
│  案例——在 MBA 的危机公  │
│  关课上。               │
│                        │
│ ────────────────────── │
│  五维结算迷你图          │ ← 五条迷你数值条
│                        │
│  预制黑客松模拟器        │ ← LOGO + "图鉴 NO.03/12"
│  你也能办一届 → 扫码(伪) │ ← 传播钩子 + 装饰性伪二维码
└────────────────────────┘
```
- 12 张结局卡共用版式、各配一张像素插画 + 专属红头文号
- 游戏内"保存图片"按钮即导出；**UI 其他页面右下角常驻迷你 LOGO 水印**，任何录屏截图都自带出处

## 5. 音效与 BGM（8-bit）

| 场景 | 内容 | 情绪 |
|---|---|---|
| 筹备期 | 轻快 chiptune loop（办税大厅排队叫号感） | 一本正经地忙 |
| 比赛期·白天 | 中速 8-bit + 键盘敲击白噪 | 热火朝天 |
| 比赛期·深夜 | lo-fi chiptune 慢 loop | 键盘声像下雨 |
| 评审期 | 紧张 pulse loop | 暗箱操作的心跳 |
| 颁奖典礼 | 8-bit 版"颁奖进行曲"风格 | 荒诞的庄严 |
| 翻车/曝光 | 警报音效 + BGM 戛然而止 | 出事了 |
| SFX | 打字机（卡片文字）、翻卡、弹幕"啵"、选择确认、结局解锁音 | — |

素材来源：免费可商用 chiptune（OpenGameArt / Fesliyan Studios），WebAudio 播放，静音开关常驻。

## 6. 响应式与舒适度

- 移动端优先（传播场景在手机上）：抉择卡 max-width 420px 居中，桌面端两侧露出像素壁纸
- 全部动画 ≤200ms；所有按钮 ≥48px 点击区；无悬停依赖（hover 预览在移动端改为长按）
- 尊重 `prefers-reduced-motion`：弹幕减速、取消弹窗弹跳
- 比赛期自动暗色，其余浅色纸面——视觉节奏跟着叙事走

## 7. 实现清单（开发时对照）

0. **美术资源生产**：全部像素资源（sprite、tile、图标、结局卡插画）使用已配置好的 `image_generation` Skill 生成，prompt 模板与验收标准见《美术资源清单》；生成后统一后处理（调色板归一、透明底、放大 3 倍关抗锯齿），禁止手绘风混杂、禁止 emoji
1. Tailwind config 写入色彩 token + Fusion Pixel / Press Start 2P / 思源宋体加载
2. `<DecisionCard>` 组件（窗口壳 + 选项按钮 + 数值预览）
3. `<Hud>`（五条数值 + 热搜温度计）
4. `<BarrageLayer>`（三轨弹幕 + 对象池 + 联动发射）
5. `<PixelScene>`（Canvas：tilemap + 小人状态机 + 昼夜层 + 摄影师彩蛋）
6. `<EndingCard>`（1080×1440 Canvas 绘制 + 导出 PNG）
7. WebAudio 管理器（BGM 切换 + SFX + 静音）
