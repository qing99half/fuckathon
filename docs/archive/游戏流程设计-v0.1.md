# 《预制黑客松模拟器》游戏流程设计 v0.1

> 类型：纯前端网页游戏 · 模拟经营 + 文字事件 + 黑色幽默讽刺
> 玩家身份：黑客松主办方（"预制菜式"办赛大师）
> 核心循环：拉赞助 → 起 Title → 要场地 → 宣传招募 → 办赛 → 评审（暗箱）→ 颁奖 → 结算

---

## 一、现实黑客松流程梳理（调研结论）

### 1.1 筹备流程（赛前 1-3 个月）
1. **定主题/赛道**：起一个宏大的 Title（"AI赋能千行百业""新质生产力创新大赛"）
2. **拉赞助**：找企业赞助商出钱出奖品，赞助商要曝光权益、命题权、评委席位
3. **要资源**：找政府/园区要免费场地、要领导出席、要背书挂牌
4. **组建评委团**：企业高管 + 投资人 + 技术专家 + 政府代表（各方安插自己人）
5. **宣传招募**：发推文、做 H5 报名页、找媒体造势、高校社团拉人头
6. **定规则**：赛程（24-48h 封闭开发）、评分标准（创新性/技术性/商业性/路演表现）、奖项奖金

### 1.2 比赛流程（赛中 24-72 小时）
1. 开幕式：领导致辞（30分钟起）、赞助商宣讲、规则讲解
2. 组队/确认队伍
3. 封闭开发：选手熬夜、吃盒饭、抢插座、连不稳定的 WiFi
4. 中期检查/导师巡场（拍照素材生产环节）
5. 提交作品 + 准备路演 PPT

### 1.3 评审颁奖流程
1. **路演 Demo Day**：每队 3-5 分钟演示 + 答辩
2. **评委打分**：按评分维度打分（现实中常见权重：功能实现 60% / 代码质量 20% / 创意 10% / 惊艳度 10%）
3. **（灰色环节）利益分配**：赞助商赛道奖给自家关系户、领导打招呼、内定冠军
4. **颁奖典礼**：领导讲话 → 宣布获奖 → 合影 → 新闻通稿
5. **赛后**：奖金发放（可能拖欠）、通稿宣传、向政府/赞助商交差

### 1.4 "预制黑客松"的核心槽点（游戏梗素材库）
- Title 宏大，赛题空洞（赞助商广告命题）
- 场地靠政府白嫖，盒饭 15 元标准，选手睡睡袋
- 获奖者赛前已内定，路演只是走个过场
- 评委是赞助商市场部经理，不懂技术
- 奖金拖欠半年，奖品是"等值代币"或证书
- 领导讲话时长超过选手路演总时长
- 宣传稿阅读量 10w+，实际参赛 20 人
- 选手熬夜 48h，评审 5 分钟看完

## 二、游戏化设计草案

### 2.1 核心数值（玩家可见资源）
| 数值 | 说明 |
|---|---|
| 💰 预算 | 拉赞助和自掏腰包的钱，办赛花销 |
| 📣 声量 | 媒体曝光度，影响报名人数和政府/赞助商满意度 |
| 🤝 政商关系 | 政府和赞助商信任度，决定下一局能要到多少资源 |
| 🏆 赛事口碑 | 选手圈子里的评价，影响招募质量和"翻车"概率 |
| 😡 选手怨气 | 隐藏/半隐藏数值，攒满会触发"选手发帖曝光"事件 |

### 2.2 游戏阶段划分（单局 = 办一届黑客松）

**Phase 0 · 立项（抽卡/开局）**
- 抽取本届"命题风口"（AI、Web3、元宇宙、具身智能…不同风口影响赞助难度和媒体热度）
- 选择主办方人设背景（初创公司/行业协会/高校社团），影响初始资源

**Phase 1 · 筹备期（核心经营玩法，占单局 60%）**
回合制，每回合 = 1 周，共 6-8 回合。每回合有限行动点，分配到：
- 🏷️ **起 Title**：选择比赛名称的宏大程度（宏大 Title +声量 +政府兴趣，但 -口碑预期管理风险）
- 💼 **拉赞助**：小游戏/事件卡——陪赞助商吃饭、答应命题权、让出评委席位（赞助金额 vs 让步程度权衡）
- 🏛️ **跑政府**：申请场地/背书，需要"材料包装"（注水参赛规模预期）
- 📢 **宣传造势**：买通稿、找 KOL、做 H5（花钱换声量）
- 🍱 **后勤采购**：盒饭标准、场地桌椅、WiFi、睡袋——**省钱 vs 选手怨气**的核心博弈点
- ⚖️ **规则制定**：明面评分标准 vs 暗箱空间（给不给自己留后门）

**Phase 2 · 比赛期（事件驱动玩法，占 25%）**
- 时间轴推进 + 随机事件卡：
  - 领导致辞超时，压缩开发时间（选手怨气+）
  - WiFi 崩了（看你之前买没买好设备）
  - 有队伍是"职业选手"刷奖团（识别并处理）
  - 选手做出的东西意外优秀（你是真给奖还是照样内定？→ 道德抉择点）
  - 赞助商临时要求加广告环节
- 玩家可做有限干预：巡场拍照（+声量）、加餐（-预算 -怨气）、装死

**Phase 3 · 评审颁奖期（高潮 + 讽刺核心，占 15%）**
- 路演环节：简化呈现各队作品（每张作品卡有真实质量分）
- **评分操作台**：明面分数 + 你的暗箱操作空间
  - 每届有 N 个"招呼"要照顾（赞助商关系户、领导推荐、自己人）
  - 暗箱操作越多 → "翻车风险"累积
- 颁奖典礼小游戏：领导讲话时长控制、合影排位、新闻通稿写作（选词造句，夸大程度影响声量 vs 被扒风险）
- 奖金发放选择：足额立即发 / 拖欠 / 换成"等值权益"（省钱但怨气++）

**Phase 4 · 结算**
- 多维结算：赚钱了没？政府满意吗？赞助商续约吗？选手骂你吗？上热搜了吗（正面/负面）？
- 结局分支示例：
  - 🎉 圆满交差：各方满意，解锁更高级别赛事（省级 → 国家级）
  - 🔥 翻车曝光：选手长文《我参加的预制黑客松》10w+，政商关系清零
  - 💤 无人在意：比赛糊了，声量过低，赞助商撤资
  - 🌱 意外真诚：如果你真的好好办赛（穷但口碑爆棚），解锁"良心主办方"路线

### 2.3 长期玩法（多周目/局间成长）
- 举办届数推进，城市/级别升级：园区小赛 → 市级 → 省级 → 国际大会
- 解锁更多操作手段：请明星站台、直播带货式路演、元宇宙分会场
- 难度递增：选手越来越懂行、媒体越来越爱扒、预算越来越紧
