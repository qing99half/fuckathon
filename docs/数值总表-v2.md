## 4.9 R4d 曝光率修复（2026-09-04）

诊断结论：旧机制下每个 risk+ 选项独立 roll 曝光（p=risk/100），risk 单向累加 → 正常玩家曝光率 83%（吸收态）。

1. **检定闸门**：risk < 25 不进入翻车检定（E17 颁奖终判除外，永远 roll）
2. **降压出口**：DBT 卡 5 个破财/认错选项附带 risk 负值——CORP 婉拒 -5、CORP_API 放开 -5、SUYUN 放开 -5、JIANLI 道歉销毁 -5、PFF 补差价 -2
3. **感知提示**：risk 过 25/50/75 各弹一次氛围 toast（录音笔 / 黑幕弹幕 / 糊味），不显数字
4. **D3 认知偏差清算点 ×3**：筹备收官（recap）→ 评审开场（jintro）→ 颁奖前夜（award），条件不变（buzz≥80 且 rep≤30），fired_D3 防重复

修复后曝光率：怂玩 0% / 第一选项 9% / 全签 5% / 纯随机 78%（作死流保留）。
