# 1. 游戏概述

- **名称**：预制黑客松模拟器
- **类型**：纯前端网页游戏 · 文字事件选择（类 Reigns 卡牌抉择）+ 像素氛围场景 + 黑色幽默讽刺
- **视角**：玩家 = 黑客松主办方；选手感受用数值量化，比赛/评审期用弹幕展现选手内心 OS
- **双路线**（隐藏进入，不明选）：预制线（糊弄）vs 良心线（认真办，以 AdventureX Playbook 为蓝本）
- **单局时长**：约 10 分钟（600 秒逐秒流程见 §2）
- **Meta 目标**：13 张结局卡图鉴收集；结局卡本身即分享图（1080×1440，小红书直发）
- **上线**：GitHub（仓库：https://github.com/qing99half/fuckathon.git ）+ Vercel，纯静态，无后端，localStorage 存档
- **核心体验支柱**：① 梗密度（真实事件改编）② 多赞助混乱（预制黑客松的本性）③ 数值真实（预算硬约束、怨气不可预知）④ 截图即传播

# 2. 完整流程（五幕制 · 600 秒）

## 2.0 总览

```
序幕(0:00-1:20)   立项：开场梗 → 风口抽卡 → 起 Title → 选金主
第一幕(1:20-4:20) 筹备期：招商大会(多签！) → 场地 → 后勤三连 → 评委组建，随机事件穿插
第二幕(4:20-6:20) 比赛期：像素会场 + 弹幕常驻 + 事件卡 + 翻车随时爆
第三幕(6:20-8:20) 评审期：评委亮相 → 路演蒙太奇 → 暗箱操作台（债主冲突）
第四幕(8:20-10:00)颁奖结算：发奖方式 → 合影 C 位 → 翻车终判 → 结算 → 结局卡
```

## 2.3 第二幕 · 比赛期（4:20–6:20）

- 画面切像素会场：地图=场地决定，小人数量=Title 声量决定，设施=后勤决定，赞助商横幅=签约数量挂进展位走廊
- 弹幕常驻（三轨，怨气 A/B/C 档），玩家选择后 2 秒内联动弹幕从按钮位置发射
- 事件序列：开幕式致辞（E07，政府线必出；装死=62 分钟）→ E08 断网（公共 WiFi 60%）→ E09 刷奖团（50%，buzz≥60 则 80%）→ **E10 真神降临（必出）**："第 7 队做出全场最强作品，但他们什么背景都没有" → E11 赞助商加戏（30%+每多签 1 家+10%）→ E12 泡面门（后勤差 70%）
- **随时爆**：每次选择后 roll(100) < risk → E18 曝光事件插队；anger ≥70 先给预警事件（最后补救机会）
- 6:05 提交截止演出：小人趴倒一片，生成 8 支队伍卡

# 3. 数值逻辑（铁律摘要，全表见附录 B）

## 3.1 四条铁律
1. **预算硬约束**：花费 > 预算 → 选项置灰 + 像素锁 + "预算不足"
2. **明隐分离**：预览只显示明面四维；怨气/翻车/良心/期待值选后才反馈（HUD 脉冲 + 弹幕）
3. **四档幅度制**：S ±5 / M ±10 / L ±20 / XL ±30-40（每局 XL ≤5 处）；同卡选项拉开至少一档
4. **因果确定，反应随机**：玩家选择后果确定；概率只用于外部反应，全部死数

## 3.2 九个数值
明面：money / buzz / gov / rep / chaos(0-15)｜隐藏：anger / risk / conscience / expect

## 3.3 概率表（死数，全部可被前置选择影响）
| 事件 | 概率 |
|---|---|
| E08 WiFi 崩 | 公共 60% / 专线 0% |
| E09 刷奖团 | 50%；buzz≥60 时 80% |
| E11 加戏 | 30% + 每多签 1 家 +10%（上限 70%） |
| E11 拒加戏尾款取消 | 50% |
| 币圈尾款跑路 | 30% |
| E14 币圈评委失联 | 评委含币圈 KOL 时 30% |
| E15 直播事故 | 评委含网红博主时 40% |
| E06 不收志愿者→签到混乱 | 40%（anger+10） |
| E02 同行撞期 | 30%；离谱 Title +20% |
| E01 冠军打听 | 40%；多周目有内定前科 80% |
| E12 泡面门 | 住宿不管或 15 元盒饭时 70% |
| 翻车检定 | 每次选择后 roll(100) < risk（直播评委在场 ×1.5） |

## 3.4 混乱值三次爆炸（多赞助的代价）
- chaos≥4 → E19 环节膨胀必出（6 家致辞 3 小时）
- 含评委席位赞助 ≥2 → E20 债主冲突必出（评审期）
- chaos≥6 → E21 评委互撕必出
- 冠名奖 ≥3 → E22 奖项通货膨胀必出（"11 个奖项，8 支队"）

## 3.5 结局引擎（13 结局，优先级匹配）
曝光 > 春风(良心≥70+口碑≥80) > 意外真诚 > 戒断反应 > 代币归零 > 侄子登基 > 赞助商年会(≥6 家) > 端水艺术家(奖项≥队伍) > 刷奖团之王 > 领导满意(gov≥90) > 预制菜大师(buzz≥80+rep≤30) > 无人伤亡(buzz<30) > 圆满交差（兜底）

## 3.6 平衡验收
政府线不签赞助必寒酸；币圈线钱非约束、chaos 才是；【春风】必须穷出来；最贵组合 ≈12.8 万逼你签赞助；单局 25-30 个选择、概率事件 ≤4 个。

# 4. 美术方案

## 4.1 风格定位
**「红头文件 × 像素游戏」**：筹备/评审/颁奖期 = "组委会办公系统"（事件卡=系统弹窗、赞助协议=合同、通报=红头文件）；比赛期 = 像素俯视会场（CRT 滤镜、昼夜循环）；结局卡 = 红头文件通报版式 + 像素插画。**UI 全面禁 emoji，图标全部 16×16 像素 PNG。**

## 4.2 色彩 token
纸面米白 #F7F3EA / 墨黑 #1A1A1A / 政务红 #C8102E / 墨蓝 #1D3557 / 终端绿 #2A9D8F（良心暗示）/ 警示黄 #FFB703 / 灰 #8D99AE；比赛期深夜 #0D1B2A + 屏幕荧光 #4CC9F0；像素场景限 16 色调色板。

## 4.3 字体
Fusion Pixel（标题/窗口栏，**子集化**）/ Press Start 2P（HUD 数字）/ 思源宋体 Bold（红头文件，子集化）/ 思源黑体（正文）。字号：正文 16px、卡题 22-24px、结局卡 72px+、弹幕 14px。

## 4.4 核心组件
- **抉择卡**：弹窗壳 + 每屏一个决策 + 正文 ≤3 行 + hover 预览明面数值 + 预算不足置灰 + 良心选项绿点（不解释）
- **HUD**：五数值 + 半透明怨气条（无数字）+ 热搜温度计（绿<40/黄 40-69/红≥70）
- **弹幕**：三轨、同屏 ≤12、C 档带像素火焰前缀加速、联动弹幕从选项按钮发射
- **像素场景**：tile 16px ×3 倍渲染；小人 8 帧图集 × 运行时调色板换色；趴桌比例=f(怨气)；摄影师闪光灯彩蛋
- **结局卡**：1080×1440（3:4），红头文件版式 + "预字〔2026〕第 XX 号" + 像素插画 + 五维迷你图 + LOGO + 伪二维码；Canvas 2x 导出 PNG；全局页面常驻迷你 LOGO 水印

## 4.5 音效（8-bit）
筹备期办税大厅轻快 loop / 比赛期白天中速+键盘白噪 / 深夜 lo-fi / 评审期紧张 pulse / 颁奖 8-bit 进行曲 / 翻车警报+BGM 骤停；SFX：打字机/翻卡/弹幕啵/结局解锁。首次交互后启动，静音开关常驻。

## 4.6 响应式
移动端优先（卡 max-width 420px），桌面端两侧像素壁纸；动画 ≤200ms；按钮 ≥48px；尊重 prefers-reduced-motion；比赛期自动暗色。

## 4.7 性能硬指标（严禁降级双实现）
首屏图片 <700KB；字体子集 <800KB；音频懒加载；同屏 sprite ≤60；弹幕 ≤12 对象池；30fps。手段只有：图集合并、PNG-8、子集化、懒加载、预载、关抗锯齿、对象池。做不到砍资源数量。

# 6. 技术架构（轻量化 × 低调试成本）

- **Vanilla TypeScript + Vite，零运行时依赖**（不用 React/Tailwind）；CSS 手写 ~400 行设计 token
- **引擎不碰 DOM**：`(state, choice) → (newState, viewEvents[])`，Node 可跑；UI 只订阅事件，像素场景纯只读
- **可复现**：种子随机（KAO-XXXX）+ 选择日志 + `replay(seed, log)`；`?debug=1` 显示隐藏值/跳阶段
- **内容三道拦截**：① 构建期校验（引用完整性/四档合规/概率死数/字数上限）② `npm run simulate 1000` 机器人跑局（断言：必达结局、预算不负、13 结局可达）③ 运行时兜底（开发报 cardId，生产跳卡）
- **体积预算**：引擎 ≤800 行、UI ≤1500 行、CSS ≤400 行、脚本 ≤400 行
- **不做清单**：无账号/后端/排行榜、无多语言、无动画引擎、无状态管理/路由/UI 库、无降级双实现
- **部署**：GitHub + Vercel；加梗 = 改 JSON → simulate 200 → push

## 0. 文案总则

1. 讽刺对象是"办赛方式"，不是选手。选手永远是惨的、可爱的、值得尊敬的。
2. 互联网黑话是反派的母语：赋能、抓手、闭环、对齐、颗粒度、生态化反。
3. 数字要具体："盒饭 15 元"比"盒饭很差"好笑十倍。
4. 阴阳怪气 > 直接辱骂。弹幕的最高境界是"哈哈哈哈"后面跟着"😭"。
